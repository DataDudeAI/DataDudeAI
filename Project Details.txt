# DataDude Developer Documentation

## Overview
DataDude is a web-based analytics and campaign tracking platform that provides real-time tracking, campaign management, and deep linking capabilities. The platform is built using Flask (Python) for the backend and vanilla JavaScript for the frontend.

## Core Components

### 1. Backend (Python/Flask)

#### Database (database.py)
- SQLite database with tables for campaigns and visits
- Handles all data operations and analytics queries
- Schema includes campaign tracking and visit data storage

#### Tracking Service (tracking_service.py)
- Manages visit tracking and data collection
- Processes user agent information
- Handles campaign attribution

#### Geo Service (geo_service.py)
- Handles device and browser detection
- Processes user agent strings
- Extracts device and browser information

- Recent activity feed

#### Analytics (analytics.js)

- Timeline views

#### Campaign Management (campaign.js)

## Database Schema

### Campaigns Table


sql:datadude/Project Details.txt
CREATE TABLE campaigns (
id INTEGER PRIMARY KEY AUTOINCREMENT,
name TEXT NOT NULL,
short_code TEXT UNIQUE NOT NULL,
original_url TEXT NOT NULL,
type TEXT NOT NULL,
status TEXT DEFAULT 'active',
utm_source TEXT,
utm_medium TEXT,
utm_campaign TEXT,
created_at DATETIME DEFAULT CURRENT_TIMESTAMP
)


### Visits Table

sql
CREATE TABLE visits (
id INTEGER PRIMARY KEY AUTOINCREMENT,
campaign_code TEXT,
session_id TEXT,
ip_address TEXT,
user_agent TEXT,
referrer TEXT,
visit_data TEXT,
timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
FOREIGN KEY(campaign_code) REFERENCES campaigns(short_code)
)

## API Endpoints

### Campaign Endpoints
- `GET /api/campaigns` - List all campaigns
- `POST /api/campaigns` - Create new campaign
- `GET /api/campaigns/<short_code>` - Get campaign details
- `PUT /api/campaigns/<short_code>` - Update campaign
- `DELETE /api/campaigns/<short_code>` - Delete campaign

### Analytics Endpoints
- `GET /api/stats` - Get analytics overview
- `GET /api/visits` - Get visit details
- `POST /track` - Track new visit

## Development Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Initialize database:
   ```bash
   python check_db.py
   ```
4. Run development server:
   ```bash
   python app.py
   ```
