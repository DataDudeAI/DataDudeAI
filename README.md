## Azure AI Engineer | Machine Learning | Generative AI | LLM | MLOps

Production-oriented AI and Machine Learning projects built with **Microsoft Azure, Microsoft Foundry, Azure Machine Learning, Python, RAG, LLMs, AI Agents and MLOps**.

## Featured Projects

### 01 — Enterprise RAG Copilot

An enterprise knowledge assistant that allows users to ask questions against company documents using Retrieval-Augmented Generation.

**Architecture**

User → Streamlit → FastAPI → Azure AI Search → Microsoft Foundry Model → Grounded Response

**Key capabilities**

* Document ingestion
* Chunking and embeddings
* Vector search
* Hybrid retrieval
* RAG
* Citation-based answers
* Prompt engineering
* Response evaluation
* Content safety

**Azure Services**

* Microsoft Foundry
* Azure AI Search
* Azure Storage
* Azure AI Content Safety

---

### 02 — Azure ML End-to-End MLOps

A complete machine-learning lifecycle implemented using Azure Machine Learning.

**Pipeline**

Data → Data Preparation → Training → Evaluation → MLflow Tracking → Model Registry → Deployment → Monitoring

**Key capabilities**

* Azure ML jobs
* Reusable components
* Training pipelines
* Experiment tracking
* MLflow
* Model registration
* Managed endpoints
* CI/CD
* Model monitoring

---

### 03 — GenAI Product Analytics Agent

An AI-powered analytics assistant that converts natural-language business questions into analytical workflows.

Example:

> "Why did monthly active users decline last month?"

The system analyzes structured product data and generates:

* KPI analysis
* Trend analysis
* Segment analysis
* Possible causes
* Business recommendations

**Technologies**

Python + SQL + Microsoft Foundry + Azure ML + FastAPI + Streamlit

---

### 04 — Intelligent Document Processing

An enterprise document-processing pipeline that extracts structured information from PDFs and business documents.

**Pipeline**

Document → Azure Document Intelligence → Structured Data → Embeddings → Azure AI Search → GenAI Assistant

Use cases:

* Invoices
* Contracts
* HR documents
* Reports
* Policies
* Business documents

---

### 05 — GenAI Evaluation & Monitoring

A framework for evaluating production GenAI applications.

Metrics include:

* Groundedness
* Relevance
* Coherence
* Fluency
* Similarity
* Safety
* Latency
* Token usage

The project demonstrates how an AI application can be evaluated before and after deployment.
